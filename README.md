A Machine Learning project that predicts whether a bank customer is likely to **churn (leave)** using customer demographic, product, and behavioral data.

## 📊 Dataset

* **10,127 customer records**
* **21 features**
* Target: `Attrition_Flag`
* No missing values or duplicate records

## 🔍 Project Workflow

* Data loading and exploration
* Exploratory Data Analysis (EDA)
* Data preprocessing and encoding
* Train-test split
* Model building and evaluation
* Feature importance analysis
* Hyperparameter tuning

## 🤖 Models Used

* Decision Tree
* Random Forest
* Gradient Boosting
* Tuned Gradient Boosting

## 🏆 Best Model

**Gradient Boosting** was selected as the final model because it provided the best balance between accuracy, precision, recall, and F1-score.

## 🛠️ Technologies

Python • Pandas • NumPy • Matplotlib • Seaborn • Scikit-learn
